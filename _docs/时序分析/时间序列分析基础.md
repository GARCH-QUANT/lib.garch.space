# 时间序列分析基础

## 1. 随机过程与平稳性

### 严平稳（Strict Stationarity）
$$\{X_t\} 	ext{ 若对所有 } k, t_1,\ldots,t_k 	ext{ 有 } (X_{t_1},\ldots,X_{t_k}) \stackrel{d}{=} (X_{t_1+h},\ldots,X_{t_k+h})$$

### 宽平稳（Weak Stationarity / 二阶平稳）
$$\mathbb{E}[X_t] = \mu, \quad \text{Cov}(X_t, X_{t+h}) = \gamma(h) \text{ 仅依赖于 } h$$

## 2. ARMA(p,q) 模型

$$X_t = c + \sum_{i=1}^{p} \phi_i X_{t-i} + \epsilon_t + \sum_{j=1}^{q} \theta_j \epsilon_{t-j}$$

- **AR(p):** 自回归项，捕捉序列自身的惯性
- **MA(q):** 移动平均项，描述白噪声的累积效应
- **平稳性条件：** $\phi(B) = 1 - \phi_1 B - \ldots - \phi_p B^p = 0$ 的根全在单位圆外

## 3. 单位根与随机趋势

### ADF 检验（Augmented Dickey-Fuller）

$$\Delta X_t = \alpha + \beta t + \gamma X_{t-1} + \sum_{i=1}^{p} \delta_i \Delta X_{t-i} + \epsilon_t$$

原假设 $H_0: \gamma = 0$（存在单位根），若拒绝则序列平稳。

### KPSS 检验
原假设为平稳性，与 ADF 形成互补。

## 4. 协整与向量误差修正模型

### Engle-Granger 两步法
1. 长期均衡回归：$Y_t = \alpha + \beta X_t + u_t$
2. 对残差 $\hat{u}_t$ 进行 ADF 检验，若平稳则存在协整关系

### VEC Model
$$\Delta Y_t = \Pi Y_{t-1} + \sum_{i=1}^{p-1} \Gamma_i \Delta Y_{t-i} + \epsilon_t$$

其中 $\Pi = \alpha \beta^\top$ 包含协整向量的调整速度信息。

## 5. 谱分析基础

### 谱密度函数
$$\gamma(h) = \int_{-\pi}^{\pi} e^{ih\omega} f(\omega) d\omega, \quad f(\omega) = \frac{1}{2\pi} \sum_{h=-\infty}^{\infty} \gamma(h) e^{-ih\omega}$$

低频（$\omega \approx 0$）主导 $\Rightarrow$ 长期趋势
高频（$\omega \approx \pi$）主导 $\Rightarrow$ 短期噪声
