# 概率统计基础

## 1. 随机变量与概率分布

随机变量 $X$ 是定义在概率空间 $(\Omega, \mathcal{F}, \mathbb{P})$ 上的可测函数。

### 1.1 正态分布

$$X \sim \mathcal{N}(\mu, \sigma^2)$$

概率密度函数：

$$f(x) = \frac{1}{\sqrt{2\pi\sigma^2}} \exp\left(-\frac{(x-\mu)^2}{2\sigma^2}\right)$$

### 1.2 学生-t 分布

$$X \sim t_{\nu}(\mu, \sigma^2)$$

适用于金融收益的肥尾特征建模。

## 2. 统计推断

### 2.1 最大似然估计（MLE）

给定观测样本 $\{X_1, ..., X_n\}$，似然函数：

$$\mathcal{L}(\theta) = \prod_{i=1}^{n} f(x_i | \theta)$$

对数似然：

$$\ell(\theta) = \sum_{i=1}^{n} \log f(x_i | \theta)$$

## 3. 极值理论（EVT）

用于建模市场极端收益：

$$P(X > x) \approx \frac{1}{1 + \xi(x)/\sigma_u)^{-1/\xi}}$$
