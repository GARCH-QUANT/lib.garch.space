# 概率统计进阶

## 1. 多元正态分布

### 密度函数
$$f(x) = \frac{1}{(2\pi)^{p/2} |\Sigma|^{1/2}} \exp\left(-\frac{1}{2}(x-\mu)^\top \Sigma^{-1}(x-\mu)\right)$$

### 条件分布
若 $(X,Y) \sim \mathcal{N}_{p+q}(\mu, \Sigma)$，则 $X|Y \sim \mathcal{N}(\mu_{X|Y}, \Sigma_{X|Y})$，其中：
$$\mu_{X|Y} = \mu_X + \Sigma_{XY}\Sigma_{YY}^{-1}(Y-\mu_Y)$$
$$\Sigma_{X|Y} = \Sigma_{XX} - \Sigma_{XY}\Sigma_{YY}^{-1}\Sigma_{YX}$$

## 2. 稳定分布（Stable Distributions）

金融收益率通常不服从正态分布，而更接近**稳定分布（Stable Paretian Distribution）**：

$$X \sim S(\alpha, \beta, \gamma, \delta)$$

- $\alpha \in (0,2]$：特征指数，$\alpha=2$ 即正态分布，$\alpha<2$ 意味着肥尾
- $\beta \in [-1,1]$：偏度参数
- $\gamma > 0$：尺度参数
- $\delta \in \mathbb{R}$：位置参数

**特征函数：**
$$\mathbb{E}[e^{iuX}] = \exp\left\{iu\delta - |\gamma u|^\alpha\left[1 - i\beta \cdot \text{sgn}(u)\tan\frac{\pi\alpha}{2}\right]\right\}$$

## 3. 极值理论（Extreme Value Theory, EVT）

### GEV 分布（广义极值分布）
$$G(z) = \exp\left[-\left(1 + \xi \frac{z-\mu}{\sigma}\right)^{-1/\xi}\right], \quad 1+\xi(z-\mu)/\sigma > 0$$

- $\xi = 0$：Gumbel（指数尾）
- $\xi > 0$：Fréchet（厚尾幂律）
- $\xi < 0$：Weibull（有限尾）

### POT 模型（Peaks Over Threshold）
$$P(X > x | X > u) \approx \exp\left(-\frac{x-u}{\sigma}\right), \quad x > u$$

## 4. Copula 相依结构

### Sklar 定理
对边缘分布 $F_1,\ldots,F_n$，存在 Copula $C$ 使得：
$$H(x_1,\ldots,x_n) = C(F_1(x_1),\ldots,F_n(x_n))$$

### 常用 Copula

| 类型 | 参数 | 特点 |
|------|------|------|
| Gaussian Copula | $\rho$ | 对称相关，无尾部依赖 |
| t-Copula | $\rho, \nu$ | 对称相关 + 尾部依赖 |
| Clayton Copula | $\theta$ | 下尾相关强，上尾弱 |
| Gumbel Copula | $\theta$ | 上尾相关强，下尾弱 |

### Copula-GARCH 联合建模
$$H_t(x,y) = C_{\theta}(F_t(x), G_t(y))$$
可捕捉金融市场间的**非线性相依**和**尾部传染**效应。

## 5. 极大似然估计的渐近理论

设 $\theta \in \Theta \subset \mathbb{R}^p$，对数似然 $\ell_n(\theta) = \sum_{t=1}^{n} \log f(x_t|\theta)$：

###  regularity 条件
1. 参数空间 $\Theta$ 为开集
2. $f(x|\theta)$ 对 $\theta$ 三阶可导
3. 信息矩阵 $I(\theta) = -\mathbb{E}[\partial^2 \log f / \partial \theta \partial \theta^\top]$ 正定

### 渐近性质
$$\sqrt{n}(\hat{\theta}_{MLE} - \theta_0) \xrightarrow{d} \mathcal{N}(0, I(\theta_0)^{-1})$$
